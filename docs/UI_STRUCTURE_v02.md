# 크루 운영 플랫폼 — 화면 구조 v0.2 (승인안)

작성일: 2026-11-10 · 기준: UI_STRUCTURE_v01.md를 이어받고, 아래 승인 결정을 반영한다.
기능·상태·권한·저장 규칙은 기능 명세서 v0.3을 그대로 유지한다. 이후 기능은 임의로 추가하지 않는다.

## 승인한 결정

1. 크루장 미션 목록은 표 형태로 바꾼다. (크루원은 카드 유지)
2. 미션 상세를 열 때 탭: 검토 대기가 있으면 항상 '제출물 검토'. 검토 대기가 없으면 미션 목록에서는 '개요', 홈의 `검토하기`·미션 등록 직후에는 '제출물 검토'.
3. 관리자 화면도 같은 틀: 전체 크루 → 구성원 목록(탐색형) → 개인 상세(상세형 + 탭).
4. 관리자의 미션 상세 열람은 이번에 넣지 않는다.

## 원칙

- 계층은 크루 → 미션 → 대상자(제출물). 위치 표시가 이 계층을 그대로 보여준다.
- 업무는 전역 메뉴가 아니라 그 업무가 속한 상세 화면의 탭 안에서 처리한다. 퀵 리뷰 = 미션 상세 › 제출물 검토 탭.
- 화면 틀은 세 가지: 탐색형(홈·목록), 상세형(위치 → 머리 → 탭 → 내용), 작업 영역(탭 안의 필터 → 목록 | 상세).

## 역할별 메뉴

| 역할 | 상단 메뉴 |
| --- | --- |
| 크루원 | 홈 · 미션 · 크루 소통 |
| 크루장 | 홈 · 미션 · 크루 소통 · 알림 미리보기(시연) |
| 관리자 | 전체 크루 · 알림 미리보기(시연) |

## 화면 연결

```text
[크루원] 홈 → 미션 상세 / 미션 목록 → 미션 상세 (제출·수정본·게시 기록)
[크루장] 홈 검토하기 → 미션 상세 › 제출물 검토
         미션 목록(표) → 미션 상세 › 개요 ⇄ 제출물 검토
         미션 등록 → 새 미션 상세 › 제출물 검토
[관리자] 전체 크루 → 크루 구성원 목록(표) → 개인 상세 › 활동 | 콘텐츠 성과 | 광고·커머스 제안
```

## 공통 레이아웃

- 상단: CREW | 메뉴 | 현재 예시 사용자·소속 | 시연 도구(접기/펼치기)
- 콘텐츠 최대 폭 1200px. 읽기 위주 탭은 840px, 작업 탭은 전체 폭.
- 페이지 제목 28px, 탐색 화면 구역 간격 32px.
- 좁은 화면: 표의 행은 카드처럼 쌓이고, 작업 영역은 필터 → 목록 → 상세 순으로 세로 배치.
