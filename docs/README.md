# 크루 플랫폼 제작용 디자인 패키지 v0.4

2026-11-09 · 기능 명세 v0.3 기준

1. prototype-spec.md: 업무·상태·접근 범위·제작 단계의 기준.
2. design-system.md: 통합 디자인 규칙. 12절의 지시문을 제작 도구에 전달.
3. tokens.css: CSS 토큰. 앱의 src/styles로 복사해 전역에서 한 번 로드.
4. preview.html + preview.css: 정적 스타일 견본. tokens.css와 같은 폴더에서 preview.html을 브라우저로 연다.
5. references.md: 자료별 적용 원리와 제외 범위.

미리보기는 실행 앱이 아니다. 여러 장면의 수치는 독립 예시다. 실제 저장·알림·역할 전환·접근 검사·T-01~12는 앱 구현 후 검증한다.

글꼴은 Wanted Sans이며 미리보기에서 외부 CDN을 사용한다. 인터넷이 없으면 한국어 시스템 글꼴로 표시된다. 앱은 npm 패키지를 사용한다.

현재 기준 문서는 design-system.md 하나다. 첨부 원본이나 이전 문서를 동시에 적용하지 않는다. 회사 공식 HEX는 미확정이며 선명한 오렌지 #FF7A00을 제작값으로 사용한다.

배포 ZIP의 output 폴더는 과거 스토리보드·제작 지시문 참고용이다. 현재 제작 기준은 docs의 7개 파일이며 시작 지시문은 design-system.md 12절을 사용한다.
