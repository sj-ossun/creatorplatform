## 4·4.5단계 추가 결정 (사용자 확정)

| 항목 | 결정 |
| --- | --- |
| 이름 | '소통' → '커뮤니티' |
| 커뮤니티 | 목록 → 상세 전환. `글 작성` 하나에서 구분 선택: 크루장 공지·글·질문, 크루원 글·질문. 공지는 진한 바탕 강조, 일반 글은 구분 표시 없음, 질문은 작은 태그. 정보는 `작성자 \| 날짜 \| 시각 \| 댓글 n`처럼 세로선으로 구분 |
| 홈 가이드 버튼 | 소개 문구 아래 버튼 삭제 (헤더 메뉴·아래 안내 구역 유지) |
| 우수 사례 | 완료 + 게시 기록이 있는 결과물을 크루장(자기 크루)·관리자(담당 크루)가 한 줄 평과 함께 지정. 홈 배너(최근 1건) → 공개 '우수 사례' 페이지. 실제 게시 URL·최신 조회수·한 줄 평. 시연 데이터는 '시연용 가상 사례' 표시. 꾸며낸 실적·후기는 넣지 않음 |
| 알림함 | 로그인한 모든 역할. 크루원: 새 미션·피드백·공지 / 크루장: 새 제출·수정본·질문 / 관리자: 검토 지연(2일 넘은 제출)·제안 상태 변경(다른 사람이 바꾼 것). 앱 안 알림이며 외부 발송 없음. 알림은 기록에서 계산하고 '마지막으로 연 시각'만 저장 |
| 내 제안 | 크루원 본인만, '제안 전달' 이후 상태만 읽기 전용. 내부 메모 비노출. 크루장은 볼 수 없음. 수락·거절·정산 없음 |
| 저장 형식 | v3 → v4: 우수 사례 목록·읽음 시각만 추가. 처음 저장 직전 원래 값을 `crew-prototype/backup-v3`에 한 번 백업. 기존 기록·ID·키는 그대로 |
| 5단계 (별도 설계 예정) | 수익 기록(관리자만 입력, 정산 아님)·성과 대시보드(그래프). 크루장은 크루원별 수익을 볼 수 없음. 순위는 보이지 않으며 관리자 전용 여부를 검토 |
