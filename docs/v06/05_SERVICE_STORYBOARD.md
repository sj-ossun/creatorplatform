# 전체 이용 스토리보드 v0.6

## 1. 처음 방문한 크루원

| 컷 | 화면 | 보이는 내용 | 사용자 행동 | 다음 상태 |
|---|---|---|---|---|
| 1 | P-01 공개 홈 | 소개 문구·포스터·활동 설명·상단 로그인 | 로그인 선택 | P-12 |
| 2 | P-12 | 크루원·크루장·관리자 진입, 시연 안내 | 크루원 가상 계정 선택 후 로그인 | P-01 로그인 홈 |
| 3 | P-01 | 기존 소개와 계정 이름, 내 크루 바로가기 | 상단 크루 활동→미션 | P-03 |
| 4 | P-03 | 배정 미션의 제목·기한·내 상태 | 미션 선택 | P-04 |
| 5 | P-04 | 기준·제출 형식·다음 행동 | 결과물 제출 | 검토 대기 |
| 6 | P-04 | 버전별 피드백·수정 방향 | 보완 요청일 때 재제출 | 기존 기록 보존·검토 대기 |

핵심: 로그인 성공 직후 바로 작업 화면으로 보내지 않는다. 처음 보는 사용자도 상단 메뉴에서 미션을 찾을 수 있어야 한다.

## 2. 반복 방문한 크루장

1. 공개 홈에서 로그인 → 크루장 계정 → 같은 홈.
2. 홈에 표시된 검토 대기 요약 또는 상단 크루 활동→미션을 선택.
3. P-04에서 미션 맥락·대상·상태를 확인한 뒤 P-05 퀵 리뷰로 이동.
4. 제출 버전·이전 피드백을 확인하고 처리 결과·설명을 저장.
5. 처리한 결과는 읽기 전용으로 남고 다음 대기로 이동. 대기가 없으면 빈 상태.
6. 미션 상세·목록·홈으로 돌아갈 경로가 항상 있다.

새 미션은 P-03→P-06→등록 성공 후 P-05. 로그인 시작 흐름만 바꾸고 기존 등록 후 경로는 유지한다.

## 3. 관리자

1. P-01 → P-12 관리자 가상 계정 → P-01.
2. 상단 운영 관리 또는 홈 바로가기 → P-09.
3. 여러 담당 크루의 동일 기준 집계를 확인하고 크루를 선택.
4. 구성원 → P-10 활동·성과·제안 탭.
5. 제안 이력을 기록하되 외부 메시지를 보냈다고 표시하지 않는다.
6. 로그아웃 → P-01 공개 상태. 뒤로가기·직접 경로로 내부 기록이 다시 표시되지 않는다.

운영 화면이 아직 미구현인 단계에서는 로그인 홈에 다음 단계 안내만 표시한다. 실제 작업이 되는 것처럼 가짜 관리 메뉴를 만들지 않는다.

## 4. 가이드를 먼저 보는 방문자

1. 비로그인 상태에서 헤더 이용 가이드 → P-13.
2. 상단 목차에서 ‘미션 제출’을 선택하면 해당 구간으로 스크롤.
3. 처음 로그인하고 크루·미션을 찾는 방법을 읽는다.
4. 로그인 버튼 → P-12 → P-01. 가이드로 돌아오려면 상단 메뉴 이용.
5. 관리자 절차는 관리자 로그인 후만 가이드에 추가된다. 공통 공개 안내에는 개인 자료를 넣지 않는다.

## 5. 예외 여정

- 비로그인 사용자가 보호 페이지를 요청: 내용 대신 로그인 안내 → P-12 → P-01 → 권한이 맞으면 ‘선택했던 기능으로 이동’. 자동 우회 이동 없음.
- 잘못된 역할: 로그인 상태여도 접근 불가. 타인 이름·미션 제목은 노출하지 않고 홈 복귀.
- 소속 크루 없음: 홈과 가이드는 이용 가능, 크루 활동에는 배정 없음 안내. 허위 미션·크루를 생성하지 않는다.
- 미저장 입력 상태에서 로그아웃: 확인 취소 시 그대로 유지; 승인 시 입력·세션만 해제하고 업무 기록 유지.
- 알림 예시: 같은 계정은 연결 미션으로; 다른 계정 또는 비로그인은 로그인 안내 → 홈 → ‘선택했던 피드백 보기’. 자동으로 계정을 바꾸지 않는다.

## 6. 사용자 관찰 과제

‘이 서비스가 무엇을 돕는지 설명해 주세요’, ‘크루원으로 로그인해서 미션을 찾아주세요’, ‘관리자로 로그인해서 한 사람의 제안 이력을 찾아주세요’, ‘가이드에서 수정본 제출 방법을 찾아주세요’를 제시한다.

메뉴 발견 여부·되돌아간 지점·진행자 도움·소요 시간·잘못 이해한 역할을 기록한다. 퀵 리뷰 속도나 장기 리텐션을 이 탐색 테스트만으로 입증하지 않는다. 합격 수치는 테스트 전에 합의한다.
