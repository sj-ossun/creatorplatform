## 1. 화면 역할

| 화면 | 한 줄 역할 | 담는 것 | 담지 않는 것 |
| --- | --- | --- | --- |
| 공개 홈 | 처음 온 사람에게 서비스 소개 | 소개 문구, 카테고리, 이번 주 미션 미리보기, 이용 방법, 우수 사례, 후기, 로그인 안내 | 가입·합류 신청, 금액·정산 |
| 크루원 홈 | 로그인 직후, **크루를 가리지 않는 입구** | 내 현황 숫자, 가장 먼저 할 일 1건(요약), 이번 주 남은 할 일, 새 소식(광고 제안·공지·답변), 크루방 바로가기, 전체 크루 게시판 | 미션 상세, 피드백 전문, 완성한 콘텐츠, 크루 둘러보기, 프로필 카드 |
| 크루방 | **한 크루의 작업 공간** | 크루 소개, 공지, 이번 주 할 일 전체, 최근 게시물, 내 진행 상황(달성률·마감 달력), 내 질문 | 다른 크루 소식, 전체 크루 게시판 |

판단 기준: "지금 확인해야 하는가?"는 홈, "자세히 보고 작업해야 하는가?"는 크루방.

## 2. 디자인 원칙

1. **주황 버튼은 화면에 하나.** 그 화면에서 가장 급한 행동에만 쓴다. 크루원 홈·크루방에서는 마감이 가장 가까운 할 일의 버튼이다. 그 할 일 카드에는 왼쪽 주황 막대를 함께 붙인다.
2. **가장 급한 할 일이 맨 위.** 할 일 목록은 마감이 가까운 순서이며, 주황 버튼·주황 막대·목록 첫 자리가 모두 같은 할 일을 가리킨다.
3. **상태는 기호 + 글자 + 색.** 색만으로 상태를 전달하지 않는다.
4. **흰 바탕, 적은 색.** 로그인 후 화면은 흰 바탕 + 먹색 + 주황 하나. 상태 색은 상태 칩 안에서만 쓴다. 여러 파스텔 색은 공개 홈에만 쓴다.
5. **일러스트는 연한 살구색.** 진한 주황(#FF6E00)은 화면 신호(로고·태그·막대·주 버튼·운영 공지 머리표)에만 쓴다.
6. **없는 기능을 있는 것처럼 보이지 않는다.** 합류 신청·정산·금액을 표시하지 않고, "크루 합류는 운영팀이 따로 안내해요"를 함께 적는다.
7. **예시 수치·예시 후기에는 반드시 '예시' 표시.** 실제 서비스에서는 빼거나 실제 값으로 바꾼다(12장).

## 5. 공통 컴포넌트

### 5.1 헤더 (로그인 후)

- 순서: 로고(`[TH 심볼] CREW` + 작은 `by Treasure Hunter`) → 메뉴 6개 → 알림 → 계정.
- 메뉴: **크루 활동▾**(크루방 · 미션) · **광고 제안** · **커뮤니티** · **내 성과** · **우수 사례** · **이용 가이드**.
- '크루 활동'은 실제 `button`이며 `aria-expanded` · `aria-controls`를 연결한다. Esc를 누르거나 바깥을 누르면 닫히고, Esc로 닫으면 초점이 버튼으로 돌아온다.
- 현재 위치 표시: 메뉴 아래 3px 먹색 선. 크루방에 있을 때는 '크루 활동'에 표시한다. 로그인 홈에는 해당 메뉴가 없으므로 표시하지 않는다(홈은 로고로 간다).
- 알림 버튼: 44×44px, 새 알림 수는 먹색 원 배지.

### 5.2 헤더 (공개 홈)

- 로고 → 이번 주 미션 · 이용 방법 · 우수 사례 → 오른쪽 검정 `로그인` 버튼.
- '크루 합류하기' 버튼은 두지 않는다.

### 5.3 버튼

| 종류 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| 주 버튼 | 주황 바탕, 흰 굵은 글자, 높이 48px, 모서리 12px | 화면당 하나: `수정본 제출하기` 등 가장 급한 행동 |
| 테두리 | 흰 바탕, 먹색 1.5px 테두리 | `미션 열기`, `크루방으로` 등 나머지 행동 |
| 검정 | 먹색 바탕, 흰 글자 | 헤더 `로그인`, 확인 창의 진행 버튼, 거절 보내기 |
| 공개 홈 알약 | 위 세 가지와 같고 모서리만 999px, 높이 52px | 공개 홈 첫 화면 |
| 밝은 알약 | 크림(`#F4EDE7`) 바탕, 진한 글자 | 공개 홈 어두운 마무리 띠 안 |

- 버튼 글자는 일어날 일을 그대로 쓴다. 같은 행동은 홈·크루방·미션 상세에서 같은 이름을 쓴다(예: `수정본 제출하기`).

### 5.4 표시

| 이름 | 모양 |
| --- | --- |
| 상태 칩 | 알약, 높이 28px, 기호 + 글자, 3.1 상태 색 |
| 카테고리 태그 | 사각 4px, 주황 1.5px 테두리 + `#FFF1E6` 바탕 + 먹색 글자 |
| 공지 머리표 | 사각 4px, 높이 24px, 12px 굵게. `[운영 공지]` 주황 바탕 + 흰 글자, `[크루장 공지]` 먹색 바탕 + 흰 글자 |
| 질문·답변·광고 제안 표시 | 사각 4px, 회색 1px 테두리, 12px 굵게 |
| 시연 표시 | `시연용 가상 사례`, `예시 수치`, `예시 후기` — 회색 바탕 또는 흰 알약 |

### 5.5 내 현황 숫자 줄 (크루원 홈)

- 흰 상자 안 4칸: 미션 달성률 · 이번 주 할 일 · 응답 대기 제안 · 새 알림. 칸마다 이름(14px) → 숫자(24px 800, 단위 14px) → 짧은 설명(13px).
- 칸 전체가 링크다. 달성률·이번 주 할 일은 크루방, 응답 대기 제안은 광고 제안, 새 알림은 알림함으로 간다.
- 모바일: 2×2 칸, 설명 줄 숨김, 칸 높이 약 68px.

### 5.6 할 일 카드 / 할 일 목록

- **가장 먼저 할 일 카드 (크루원 홈)**: 상태 칩 + 크루 이름 → 미션 제목(20px) → 한 줄 요약(피드백 전문은 넣지 않음) → 진한 마감 줄("마감 11월 19일(목) 23:59 · 2일 남음") → 오른쪽 주 버튼. 왼쪽 6px 주황 막대.
- **남은 할 일 한 줄 목록**: 상태 칩 · 제목 링크 · 마감일. 높이 48px.
- **크루방 할 일 목록**: 한 장의 카드 안에 줄마다 날짜 열(11.19 / 목 23:59) · 제목 + 상태 칩 + 한 줄 설명 · 버튼. 첫 줄(가장 급한 할 일)만 주황 막대와 주 버튼, 나머지는 테두리 버튼.

### 5.7 새 소식 목록 (크루원 홈)

- 한 장의 카드 안에 줄마다 아이콘(40px 회색 상자) · 제목 링크 + 메타 · 오른쪽 표시(광고 제안 / 크루장 공지 / 운영 공지 / 답변).
- 넣는 것: 응답 대기 광고 제안, 최근 크루장 공지, 최근 운영 공지, 내 질문 답변 도착. 피드백 도착은 '가장 먼저 할 일'에서 보여주므로 중복으로 넣지 않는다.

### 5.8 공지 띠 (크루방)

- 환영 배너 바로 아래, 이번 주 할 일보다 위.
- 흰 바탕, `#EFE8E1` 1px 테두리, 모서리 18px. 확성기 아이콘 · 공지 2줄(머리표 + 제목 + 날짜) · '공지 전체' 링크.

## 6. 화면별 구성

### 6.1 공개 홈

배경 `--lp-canvas`(#FBF7F3), 섹션은 흰 둥근 카드(32px) 또는 투명.

1. **첫 화면 (가운데 정렬)**
   - 알약 표시 `크리에이터 크루 플랫폼 CREW (가칭)`
   - 큰 제목: "혼자 만드는 콘텐츠에서, / 함께 (▶ 주황 알약) **성장하는 크루로.**" — '성장하는 크루로.' 아래에 연한 살구색 밑줄 강조
   - 설명: "미션을 확인하고, 피드백을 나누고, 활동 기록을 이어가세요. 크루장이 제출물을 보고 다음에 고칠 점을 알려줘요."
   - 버튼: 주황 `로그인하고 시작하기` + 테두리 `이번 주 미션 보기`
   - 아래 작은 글: "시연용 가상 계정으로 로그인해요 · 크루 합류는 운영팀이 따로 안내해요"
   - 장식: 연한 살구색 반짝이 3개 + 궤도 선(모바일에서는 일부 숨김)
2. **숫자 줄**: 활동 중인 크루원 45명 · 누적 조회수 · 기한 내 제출률 + `예시 수치` 표시
3. **카테고리 타일 5개**: 푸드 · 여행(활동 중인 크루 수) / 카페 · 뷰티 · 리빙(`크루 준비 중`, 그림 흐리게). 칸마다 3.1 카테고리 색, 입체 그림. 데스크톱 5열(2·4번째 14px 아래로), 모바일 2열 + 마지막 한 줄 전체.
4. **이번 주에 만들어볼 미션**: 카드 3장(첫 장은 주황 바탕 강조). 크루·마감 D-n, 제목, 한 줄 설명, 그림, 제출 형식, 원형 화살표(→ 로그인). **금액 없음.** 아래에 "미션은 크루에 등록된 크루원에게 배정돼요. 크루 합류는 운영팀이 따로 안내해요."
5. **미션 하나가 기록으로 남기까지**: 1 미션 확인 → 2 제출하고 피드백 받기 → 3 활동 기록 이어가기
6. **우수 사례**: 최대 3건. `시연용 가상 사례`, 카테고리 · 크루, 성과 한 줄, 조회수는 "크리에이터 직접 입력, ○월 ○일 확인". 크리에이터 이름·링크는 넣지 않는다. 링크 `크루로 로그인하고 자세히 보기`
7. **크루원 후기 (예시)**: 색 카드 3장, `(예시)` 표시
8. **마무리 띠**: 어두운 바탕(`#231C18`), "혼자보다 크루와 함께 / **더 꾸준히**(주황 바탕) 만들어요", 밝은 알약 `로그인하고 시작하기`, 합류 안내 문구

## 7. 일러스트

- 직접 그린 단순 도형 SVG만 쓴다. 참고 이미지의 그림·캐릭터를 따라 그리지 않는다.
- 색: 연한 살구색 `#FFC9A0` · `#FFDDBF` · `#FFB98A`, 크림 `#FFF1E6`, 흰색, 먹색 외곽선(3px). 진한 주황 `#FF6E00`은 쓰지 않는다. 단, 공개 홈 카테고리 타일과 미션 카드 그림은 예외로 입체 그라데이션을 쓴다.
- 캐릭터: 셰프 모자를 쓴 콩 모양 크루원. 크루원 홈 환영 상자와 크루방 배너에 쓴다.
- 장식 그림은 `aria-hidden="true"`로 처리하고, 의미 있는 정보는 글자로도 적는다.
- 사진·실제 인물 이미지는 쓰지 않는다.

## 9. 접근성 확인

- [ ] 상태는 기호 + 글자 + 색으로 구별된다.
- [ ] 링크·버튼·메뉴는 누르는 높이 44px 이상이다(375·390px 포함).

- [ ] 장식 SVG는 `aria-hidden`이다.
- [ ] 화면에 주황 버튼이 하나뿐이다.

## 12. 남은 확인 사항

- **예시 수치·예시 후기**: 공개 홈의 누적 조회수·제출률과 크루원 후기는 견본용 예시다. 확정 원칙("꾸며낸 실적·후기·가짜 활동 수 금지")에 따라 실제 서비스에서는 빼거나 실제 데이터로 바꾼다. 프로토타입 v2에 넣을 때도 `예시` 표시를 유지한다.
