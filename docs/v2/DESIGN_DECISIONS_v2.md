# 프로토타입 버전 2 디자인 결정 (2026-11-18, 사용자 승인 견본)

버전 2는 `prototype-v2/`에 따로 만든다. 버전 1(`src/`)과 그 단일 HTML 파일은 고치지 않는다(나중에 비교용).
기준: [디자인 시스템 v0.7](05_DESIGN_SYSTEM_v07.md) + 사용자 견본 v3 + 승인한 v2 견본.

| 항목 | 결정 |
| --- | --- |
| 저장 위치 | 버전 1과 따로: `crew-prototype-v2/data`, `crew-prototype-v2/session`. 저장 형식은 버전 1과 같은 v9 |
| 상단 메뉴 (5개) | 크루원: 크루 활동▾(크루방·미션·커뮤니티) · 광고 제안 · 내 성과 · 우수 사례 · 이용 가이드. 크루장: 크루 활동▾(크루방·미션·커뮤니티·성과) · 광고 제안 · 우수 사례 · 이용 가이드. 관리자: 운영 관리 · 커뮤니티 · 우수 사례 · 이용 가이드 |
| 공개 홈 메뉴 | 이번 주 미션 · 이용 방법 · 우수 사례(같은 페이지 구역으로 이동) + 검정 `로그인` |
| 960px 이하 헤더 | 메뉴가 두 번째 줄로 내려감(≡ 메뉴 버튼 없음) |
| 메뉴 이름 | 크루원 '내 제안'·크루장 '받은 제안' → 둘 다 `광고 제안` |
| 캐릭터 | 요리사 모자 그림 대신 사용자 분홍 캐릭터(배경 제거). 크루원·크루장 홈 환영 상자와 크루방 머리에. 359px 이하 숨김 |
| 공개 홈 순서 | 첫 화면 → 수치(`예시 수치`) → 카테고리 5칸 → 크루원 후기(예시, 별점 5·4·5) → 이용 방법 → 이번 주 크루 미션 → 우수 사례 → 마무리. 주황 버튼은 `로그인하고 시작하기` 하나. 진행 중 미션이 없으면(예시 데이터) 최근 미션을 `마감 지남`으로 보여줌 |
| 로그인 홈 (세 역할 같은 뼈대) | 환영 상자(인사 + 내 현황 숫자 + 캐릭터) → 왼쪽 [가장 먼저 할 일 · 새 소식] / 오른쪽 [크루방 바로가기(테두리) · 전체 크루 게시판]. 크루장은 '검토를 기다리는 미션'(주황 `검토하기`)과 미제출 펼침, 관리자는 회색 환영 상자 + 주황 `운영 관리로` + 공지사항 흰 띠 + 새 소식 + 커뮤니티. 크루 둘러보기·우수 사례 배너·공지 상자는 홈에서 뺌 |
| 크루 공간 | 왼쪽 흰 크루 메뉴 카드(크루방·미션·커뮤니티(·성과), 커뮤니티 안에서는 게시판 4개를 들여 씀, 아래 이용 가이드 카드). 휴대폰은 위 가로 탭 + 게시판 칩. 퀵 리뷰는 넓게 쓰려고 카드 없이 |
| 크루방 공지 | 주황 테두리 대신 흰 띠 |
| 미션 상세 | 제목 아래 한 줄(상태·마감 표시·마감·형식). 크루장 피드백은 흰 카드 안 회색 상자, 제출 칸은 왼쪽 주황 막대 카드, 목표·기준(접힘)은 제출 칸 아래, 제출·피드백 이력도 카드 |
| 광고 제안 | 제목 아래 한 줄 안내, 응답을 기다리는 제안 카드에 왼쪽 주황 막대, 크루원 수락·거절 아래 '수락하면 확인 창이 한 번 더 떠요' |
| 지난 링크와 같음 | 바로 앞 제출과 같은 링크로 다시 내면 제출 이력(퀵 리뷰·미션 상세)에 `지난 링크와 같음` 표시 |
| 나머지 화면 | 배치는 그대로, v0.7 색·모양(버튼 1.5px 테두리, 컨트롤 12px·카드 20px 모서리 등)만 |
